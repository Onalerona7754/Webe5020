 Hope Haven Animal Shelter - Website Project

A responsive, multi-page website designed for Hope Haven Animal Shelter, a non-profit organization dedicated to rescuing, rehabilitating, and rehoming domestic animals. This project implements modern semantic HTML5 structure, custom external CSS styling, interactive user elements, and a responsive mobile-first layout.
